# 2.0 兼容基线夹具

全部为手工构造的合成数据，不来自真实账号、游戏会话或用户配置。`synthetic-account` 是固定测试标识，游戏名称和规则名称为占位数据；设置未启用认证，不包含哈希、盐或密码。

| 文件 | 用途 |
| --- | --- |
| ledger-v1.json | 旧账本：90 秒实测、8 分钟聚合估算，迁移后历史明细未知 |
| ledger-v2-audit.json | 新账本：90 秒实测，Steam 差值 8 分钟后手动修正为 5 分钟；游标仍为 108 |
| settings.json | 当前默认时间参数、声音关闭、自启关闭、无认证配置 |
| rules.json | 全局每日仅提醒与单游戏每周强退并存，不代表真实执行过强退 |
| game-categories.json | 用户将合成条目分类为工具；分类不移出限额范围 |
| backup-without-categories.json | 旧备份缺少分类字段，恢复后分类应回到未知，保留旧分钟及余数 |
| backup-v2.json | 完整 v2 审计、游标、规则、设置、分类恢复及重启对照 |

`BaselineCompatibilityTests` 通过生产 Runtime 恢复/重启路径读取备份，并验证精度、审计、游标和规则。测试使用临时目录、空进程目录和不写注册表的自启适配器。其他单文件夹具为同一批数据的独立样本，供后续 UI/迁移验证使用；不把合成结果当成真实游戏或系统安装验收。
