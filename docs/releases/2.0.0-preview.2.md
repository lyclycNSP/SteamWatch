# SteamWatch 2.0.0-preview.2

用于个人自用和早期开源反馈的 Windows x64 预览候选。此文件是 GitHub Pre-release 说明草稿，不表示已经创建标签、上传附件或公开发布。开发自动化的空白窗口及显示状态对照结果见下方已知问题，不将环境条件下复验通过称为所有环境已根治。

## 下载文件

- SteamWatch-win-x64.zip：绿色版，完整解压后运行根 SteamWatch.exe。
- SteamWatchSetup-win-x64.exe：安装版，安装到当前用户目录。
- 对应 .sha256：下载完整性校验。
- SteamWatch-win-x64.manifest.json、release-manifest.json 及其校验：逐文件、版本、构建和签名信息。

发布包包含运行组件，无需安装开发工具。包未签名；系统可能警告或拦截，详见 [已知问题](../known-issues.md)。

## 主要更新

统一界面、游戏库内日周规则、明确的每周期提醒/强退策略、实测与估算分离、估算审计修正、最新提醒合并、设置草稿/退出恢复，以及更清楚的绿色入口和安装流程。完整列表见 [CHANGELOG](../../CHANGELOG.md)。

## 从 1.2.0 升级

1. 在旧版导出完整备份并正常退出，保留旧程序和旧数据副本。
2. 绿色版建议解压到新目录，再复制旧 data 或从完整备份恢复；安装版运行新安装器，并检查数据目录与规则。
3. 启动后核对历史统计、总限额、单游戏规则、分类和认证设置。估算迁移保留未知来源标识，不补造旧版没有记录的明细。

2.0 使用新版账本。需要回退时使用升级前的数据备份和旧程序，不让旧程序直接写入新版 data。

## 测试范围与已知问题

已进行本机自动化和用户日常使用检查；本机环境含 Windows 11 x64。完整系统/缩放/高对比度、干净 Windows、周一跨周及全部真实游戏执行组合未完成。开发自动化中曾出现偶发空白窗口，根因未确认。详见 [已知问题](../known-issues.md)。
