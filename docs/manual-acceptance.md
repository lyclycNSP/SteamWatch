# SteamWatch 手工验收

自动测试和构建不替代以下真实 Windows 验收。执行前备份数据；强退实验使用可丢弃进度的测试游戏。

本文件是操作检查清单，不表示各项已通过。当前结果见 本地 `STATUS.md`，任务归属见 本地 `PLAN.md`。各项按最终受测包执行；层级和证据要求见 [测试策略](test-strategy.md)。下方先列基础检查，再按界面/运行/安装列专项，不复制通过数量。

## 启动与目录

- 绿色版完整解压后启动根 SteamWatch.exe，portable.marker 保留，data 位于根启动器旁，依赖在 app。
- 安装版程序与数据分别位于 LocalAppData/Programs/SteamWatch 和 LocalAppData/SteamWatch。
- 旧 data 迁移后原文件保留；再次启动不覆盖现有新数据。
- 同一目录再次启动唤起已有窗口；不同绿色版数据目录各自独立。

## 计时与界面

- 三次 20 秒会话累计约 1 分钟，而非每次 1 分钟；允许进程采样误差。
- 游玩期间刷新不丢余数，退出再开保留秒以下余数。
- 跨午夜/周一归属正确；睡眠不增加本地实测时长。
- 暂停限制时继续计时，不提醒或强退；恢复后重新给予宽限。
- 多游戏库均可显示；搜索、运行中、单游戏规则筛选可组合。
- 限额概览显示用量、剩余和倒计时；统计区分估算补记。
- 多条强退规则并存时，汇总显示最早目标与预计时间；暂停/无运行目标时不显示过期威胁。
- 游戏/工具分类明确标记为用户设置，未知条目不隐藏，分类不改变计时与限额。
- 统计页检查当日估算，修正后有原因、前后值和备份；取消不写入，重复刷新不补回已修正部分。

## 规则、通知和关闭

- 删改前一条规则，不影响其他规则的倒计时；全局同周期只有一条。
- 限额改为 0 停用后再启用，重新给予宽限，不继承已过期倒计时。
- 改声音、关闭窗口行为不会推迟现有倒计时。
- 开启认证后，规则、常规设置、暂停恢复、备份恢复、退出和应用内卸载都需认证。
- 全屏、勿扰模式、托盘隐藏时分别验证 Toast/声音/程序内提醒。
- 测试游戏接收关闭但不退出时，宽限后才终止；权限不足、PID 消失时有正确提示。
- 保存失败不执行强退；退出前保存失败时保留应用和数据。

## 备份与升级

- 导出备份，改变规则/记录后恢复；恢复前完整备份保留。
- v1 升级保留原始账本，旧估算不编造明细；完整备份恢复同时覆盖补记明细和用户分类。
- 诊断 ZIP 仅含摘要和脱敏日志，不含账号、游戏名、个人路径、原始设置或认证配置；无日志仍可导出。
- 非法备份不能改变数据；恢复中断后重启完成同一恢复。
- 新安装、旧版覆盖升级、运行中升级接受/取消/超时、注册失败回滚分别验收；不支持协调退出的旧版本仍提示手动退出。
- 运行中升级请求正常退出；认证取消、超时或保存失败时不替换文件。旧版缺少协调协议时提示手动退出。
- 升级保留旧目录；卸载清理自启和快捷方式，保留数据，不把操作请求当作完成结果。
- 在没有开发环境的 Windows 10/11 新机验证发布包。

## 基础回归证据边界

自动回归、构建、发布脚本和临时目录事务验证见 本地 `STATUS.md`。历史结果与新版结果分别记录；未完成的真实 Steam/系统场景不能仅凭单元测试标记为验收通过。

## 界面专项：WU-ACCEPT-201 / FR-UI-001

- 在实际窗口检查游戏库统一规则入口、统计、设置、帮助及关于；旧功能对照清单中的全部入口可访问。
- 切页、反复开关详情、隐藏到托盘和再次打开后，计时持续且无重复采样循环；选中游戏、滚动位置和键盘焦点不被周期更新夺走。
- 100%、150%、200% 缩放，浅色、深色、高对比度下验证长游戏名称、窄窗口、按钮和列宽；窗口不超出工作区，次要列隐藏后详情仍可访问。
- 仅用键盘完成搜索、筛选、打开详情、编辑规则、认证及取消；检查焦点可见和读屏名称。图表同时有可读表格，不以颜色作为唯一信息。
- 运行状态与限制状态分开；暂停明确继续计时，未设限额不显示“剩余预算”，仅提醒/无目标/暂停不显示过期强退时间。
- 规则编辑目标明确；发生选择变化、规则冲突、重复提交、认证拒绝和保存失败时不修改错误对象或显示成功。
- 实测、估算、合计和 Steam 累计口径清晰；修正后的图表/表格一致，旧值冲突拒绝，原始历史未知仍标为未知。
- 常规设置即时保存失败时回退；显式保存设置有未保存提示，切页的保存/放弃/继续编辑分别验证。
- 设置分区保存只提交本分区，保留其他已保存值和认证；输入无效、文件占用、认证取消时草稿仍在原分区，可修正或重试。导航恢复原选择及焦点；认证成功保存或放弃后清空密码框。
- 在提醒页反复切换数字框焦点、保存失败/成功反馈和返回，检查控件没有横向偏移或超出视口；窄窗口设置、帮助和维护内容仍可纵向访问。
- 各敏感动作按基线矩阵逐项验证成功、错误密码、取消及忙碌冲突，包括托盘与升级请求；对话框不会叠加或阻塞后台计时。
- 实际操作打开/保存系统选择器的取消、成功、非法内容及恢复中断；诊断包与完整备份分别读回检查，不导出敏感材料作为截图证据。

## 计时与限制：WU-ACCEPT-202 / FR-TIME-001

- 延续基础回归中的短/长会话、刷新、跨午夜/周一、休眠/校时和账号补记验证；同时记录独立计时、活动区间、账本 ticks、日周归属及误差。
- 多个游戏并行时全局继续按各游戏用量相加；单游戏与全局日/周规则同时约束，分类过滤不改变规则范围。
- 多条规则的最早目标正确；删改、停用再启用、暂停恢复及普通设置更新不错误继承/重置倒计时。
- 先用受控程序验证保存失败、错误进程身份、PID 变化、权限不足及关闭后仍存活，再在可丢弃进度的真实游戏验证；分别记录两类证据。
- 全屏、勿扰、主窗隐藏时检查系统通知、程序提示与声音的实际结果，不因通知请求成功便标记用户可见。

## 安装专项：WU-ACCEPT-203 / FR-DELIVERY-001

- 干净 Windows 10/11 x64 记录具体 build、包哈希、用户权限和运行时状态；机器无开发工具时新装后可启动。
- 确认当前用户安装无默认提权，程序与数据目录正确，安装版不带 portable.marker；绿色版单独验证 marker 与旁边 data。
- 新装默认不开自启、快捷方式选项有效；升级保留用户自启/声音等设置，同版重装不覆盖运行数据。
- 从原自制安装器升级，检查旧 data 复制迁移、账本 v1/v2、估算审计及分类；旧注册项/PowerShell 脚本与 Inno 卸载器不会形成冲突入口。
- 运行中升级分别测试认证接受、拒绝、取消、超时及保存失败；只有保存并确认进程退出后才替换。无协议旧版本要求手动退出，不强杀。
- 注入空间不足、文件占用、注册失败及安装中断，实际检查旧程序/新程序可恢复状态及数据完整性，不把程序目录恢复推断为所有系统注册事务成功。
- 程序回退前检查数据版本兼容性；备份旧 EXE 不等于账本可降级，验证恢复步骤不会让旧版本写坏新数据。
- 卸载清理程序、自启、快捷方式和卸载项，默认保留数据；卸载后重装可恢复用户记录。程序仍运行时不以强制结束替代正常保存流程。
- 同一安装 EXE 再次安装生成新的管理目录，旧 unins000.exe 拒绝操作当前程序。从 App 发起卸载时，确认前保持应用和草稿；选择否不退出、不迁移数据；确认后检查认证/保存/正常退出。缺失卸载注册或管理文件时显示重装修复提示，帮助中的数据位置仍为安装版独立目录。
- 安装/卸载失败时核对程序、原快捷方式字节、自启值及卸载归属恢复；确认后权限/占用失败仍可重试。恢复副本默认保留，清理时不得删除活动管理目录、独立数据或尚未恢复的 journal。
- 核对主程序、安装器、卸载器签名与时间戳；未签名时如实记录。核对包内无数据、凭据或 RuntimeProbe，失败构建保留前一产物。

## 每次验收的记录要求

记录任务 ID、日期、系统/build/缩放/主题、源码或工作区标识、包版本和 SHA-256、前置状态、操作、预期、实际、误差/失败及恢复、证据路径和未覆盖范围。合成数据、受控进程、原生桌面、真实游戏和干净系统分别标注。修复后重建候选并重验受影响项；远程 CI 与正式发布另记，不合并成“全部通过”。

## 绿色版入口与搬迁

完整解压后根目录只有启动 EXE、操作指南、portable.marker 与 app；首次运行才创建 data。验证含中文/空格路径、从其他工作目录启动、重复启动只保留一个实例、整目录搬迁后原数据可读、缺失 app 时提示重新完整解压；启动/关闭无控制台窗口。开启自启后检查命令指向根入口（使用隔离 Windows 用户），移动目录后重新设置自启。安装版应仍使用独立平铺载荷，数据在 LocalAppData；不得混用绿色 ZIP。旧平铺绿色版升级保留根 data，退出并备份后更新程序文件。

### 设置草稿退出回归

- 提醒或认证分区留草稿，关闭到托盘再打开，草稿和监控保留。切为退出应用后关闭，默认继续编辑可恢复原控件。
- 窗口/托盘/升级退出分别验证保存、不保存、继续编辑；不保存后取消认证仍保留草稿，重试接受认证后才真正退出且磁盘不写入草稿。
- 草稿保存失败或认证取消不结算退出；保存认证草稿后按新密码/保护开关要求退出认证。
- 已有保存、导航或对话框时退出不得叠加操作；退出准备期间导航、编辑、托盘暂停和重复退出不得改变状态。
- 注入退出运行数据落盘失败及升级准备后提交失败，确认恢复监控、导航和草稿；应用内卸载启动失败也须恢复，真实安装目录单独验证。

### 帮助与游戏库规则布局

- 宽窗、800×600 DIP 窄窗分别检查帮助指南为标题/正文/底分隔线，五项内容直接显示，无“启动程序”折叠条目；滚动后可达认证说明及关于信息，三个设置快捷入口仍有效。
- 游戏页不再出现游戏库/限额规则切换；宽/窄窗口均从游戏库双击打开限额设置。每日/每周加载已有值，编辑不新增重复规则，删除取消不写盘、删除确认只删对应周期，顶部总限额不丢失。
- 同一游戏设置每日仅提醒、每周强退，列表应分别显示对应周期的分钟与策略，日先于周、分行排列；修改后即时更新，宽/窄窗口不遮挡策略，读屏或悬停可取得完整说明。没有单游戏规则时仍显示未设置，不将全局策略冒充单游戏策略。
- 先选游戏 A，再右键游戏 B，检查原生四项菜单及每个动作只作用 B；详情分行留白，长内容可滚动。仅有规则但已不在当前库的游戏仍能搜索、编辑和删除；没有 Steam 累计数据时不显示虚假的零值。
- 帮助滚动到底只出现指南末尾一条分隔线，关于区不重复绘线。

- 弹窗正文：检查估算补记的游戏名/摘要/依据分段、七日数值逐行间隔、估算修正确认的日期/变更/原因/备份提示。窄窗长文本可换行和滚动；恢复备份、退出确认及错误提示使用相同行高。文字缩放、其他主题和键盘滚动需人工补验。

- 每日数值的日期/实测/估算/合计列标题与数据对齐，数值按列右对齐；个位数、多位数和零值不改变列位置。连续触发限额提醒、超限与强退倒计时后，应用内只需确认最新提示一次；编辑/认证中只保留最新待显示提醒，不覆盖用户输入。之后新触发的提醒仍正常显示，系统通知和声音单独验证。

- 统计独立页面：选择不同每日/周内日期，切换标签、离开再返回、点击刷新后应分别保留。估算修正使用发起时捕获的每日日期；取消不变更数据，成功后日/周摘要、表格与七日图同步。跨年周仍为周一至周日；零分钟条目与无记录空状态区分。

- 游戏独立页：滚动到底选择游戏后点击刷新，应保留选择与滚动；设置搜索/分类/运行/规则筛选后刷新，应保留筛选。过滤掉选中游戏后不应误选其他游戏。规则编辑中请求关闭，应保持程序与编辑器，取消后正常继续；菜单、双击、每日/每周和历史条目仍按正确目标维护。

## 同代快照与操作生命周期专项

- 有实测和估算记录时，刷新后游戏实测、全局预算、日周统计及七日图应与同一账本快照一致；估算不计入预算。日周日期和游戏筛选/选择继续保留。
- 刷新读取尚未完成时，重复刷新/暂停及退出不得交错执行；退出提示当前操作未完成，原任务结束后可重试。此项需受控慢读取环境，不把普通快速刷新当作竞态已验。
- 有未保存设置草稿时请求退出并选择继续编辑，再刷新、暂停、恢复；草稿值应保留，各命令应可使用。认证取消退出后也需复验。
- 退出保存失败、升级准备后通信失败或取消时，后台循环应恢复且仅有一份；确认实测继续累计、提醒仍可触发。自动生命周期单测不代替真实游戏和原生命名管道故障验收。
- 自动故障复现：scripts/test-desktop.ps1 新增账本独占锁导致刷新留下目录 dirty、退出保存失败、解锁后等待后台补存，以及认证期间客户端断开后完成准备、恢复命令与草稿、再次正常升级退出。该脚本不启动实际游戏；活跃游戏 ticks、提醒恢复与窗口提交回调失败仍独立验收。具体通过记录以 STATUS 为准。
- 受控活跃链路：运行 scripts/test-runtime.ps1 -Mode active-exit-recovery，以实际 WMI/活动时钟识别一次性进程。锁账本→退出失败→后台失败重试→解锁自动补存/提醒→保存后取消退出→再次正常准备→重开，核对独立秒表和精确 ticks；不执行强退、不弹系统通知。此项复用监控/退出合同，属于服务级检查，不能替代上面的原生草稿、真实游戏与系统通知验收。
- 驻留成本：顺序运行 measure-residency.ps1 的可见/托盘阶段及 test-runtime.ps1 -Mode residency 的受控活动阶段，固定时长和五年合成历史，逐样本核对 CPU/工作集/private/句柄、I/O 或采样耗时，结束正常退出并校验 ticks。报告窗口状态、计时精度和首末分钟趋势；不把五分钟有界测量写成真实跨夜或没有内存泄漏的证明。

## 共享命令与页面附着专项

- 打开分类、规则、估算修正或备份/诊断文件选择器后请求退出；应用及当前输入应保留。认证交接、写入未完成期间也应拒绝退出，不得误认为弹窗关闭就已完成操作。
- 文件选择器取消后再次导出成功；规则/分类取消、估算失败和认证取消后可继续操作，不丢失原数据。维护忙碌期间设置与主导航不可修改，返回后恢复可用。
- 实际安装版卸载需独立验证退出准备可执行，取消/启动失败保留应用及草稿；绿色版只显示移除说明。
