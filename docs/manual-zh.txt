SteamWatch 操作指南

一、安装与启动
安装版：运行 SteamWatchSetup-win-x64.exe，安装到当前用户目录，无需管理员权限。
首次安装默认关闭开机启动，可稍后在设置中开启；升级保留现有偏好。
绿色版：先完整解压 ZIP，再双击根目录 SteamWatch.exe。根入口带 SteamWatch 图标；app 文件夹是运行依赖，无需进入其中寻找程序。请保留 app 和 portable.marker。不要直接从压缩包内启动，也不要只复制启动程序。
重复打开同一份数据目录会唤起已有窗口。新版本安装器可请求正常退出，仍会要求已配置的认证；拒绝、超时或保存失败则中止升级。旧版本没有退出协议时，先从托盘退出再升级。

二、计时与限额
后台每 10 秒采样，时长保留秒以下精度，界面显示完整分钟。多个短会话的余数累计，不再每次向上取整。
跨午夜按日期拆分；系统睡眠/休眠不计入本地时长。进程开始和结束检测仍存在轮询误差。
单游戏和全部游戏均可设每日/每周规则；每周为周一至周日。
游戏页顶部显示全部游戏每日、每周实测用量；点击“设置总限额”或“编辑每周限额”设置共同上限，不需要先选择游戏。
游戏页统一从游戏库管理规则，不再切换到单独规则页。双击游戏或选中后点击“设置限额”；右键游戏可设置限额、查看详情、设置强退策略或分类。限额窗口切换每日／每周加载对应已保存规则，可新建、修改或删除；取消不写入。已有规则但不在当前库中的条目仍可搜索和管理，Steam 累计数据缺失时明确说明。
游戏列表的今日/本周只显示实测；“游戏详情”可查看 Steam 累计、用户分类和适用的全部规则。统计继续包含明确标注的估算。
“单游戏限额与策略”按每日、每周分行显示时长和“仅提醒／超限强退”，两个周期可以采用不同策略；未设置规则时显示“未设置”。
全部游戏时长按各游戏相加，两个游戏同时运行会叠加。
暂停限制只暂停提醒与强退，继续计时；恢复后重新给予强退宽限期。
强退先保存数据，发送关闭请求并等待；仍运行时再核对进程身份、终止进程树并确认退出。

三、Steam 缓存补记
支持 libraryfolders.vdf 中的多个游戏库。缓存差值记为当天估算时长，在统计中标明“含估算”，不计入限额。
离线跨天记录无法从 Steam 缓存还原精确日期；首次升级旧快照会按当前账号重建基线，不追溯升级前这一段离线差值。
切换账号不会把另一账号的历史累计时长全部计入本地。本地记录仍是此设备各账号的合计。
统计 → 每日明细 → 检查／修正估算，可检查补记来源、差值依据和记录时间，并按游戏修正该日估算分钟。
统计页使用“每日明细／每周汇总”标签切换，分别显示实测、估算及合计；两个标签各自保留所选日期。
每周汇总按周一至周日显示七日趋势：实心为实测、描边为估算；“查看每日数值”可读取完整的每日数据。没有记录的日期显示 0，不补造历史。
修正原因必填，确认后先备份，保留修改前后值；只改估算，不改变实测、限额或 Steam 基线。后续刷新不会补回已删除的估算。
旧聚合估算标注“历史估算（无原始明细）”，原始发生时间未知。
限额概览汇总最早强退目标与预计时间，休眠会顺延；暂停或没有运行目标时不会显示有效倒计时。
条目可由用户明确分类为游戏或运行库／工具；信息不足显示未知，分类只影响显示筛选，不改变计时和限额。

四、数据和备份
安装版数据：%LOCALAPPDATA%\SteamWatch。旧安装目录 data 会自动复制迁移并保留原文件。
绿色版数据：解压根目录的 data，与根启动程序并列；app 内不存放新运行数据。搬迁时复制整个目录。升级前退出并备份，保留根 data，更新根启动程序和 app；不要用旧版覆盖新数据。
在设置 → 应用维护导出/恢复备份。备份包含设置、认证配置、规则、精确时长、补记明细/基线和用户分类。请妥善保管完整备份，不作为排障资料直接公开。
恢复会先保存当前完整备份；若中断，下次启动继续恢复。损坏 JSON 可从 .bak 恢复，原损坏文件保留。
旧 playtime.json 保留但新版本运行时以 playtime-ledger.json 为准。不要用旧版本覆盖新数据。
1.2.0 使用账本 v2，升级前保留 playtime-ledger-before-v2-*.json。旧版本无法读取 v2，不支持直接降级。
导出诊断包只包含版本、系统、运行计数和脱敏异常类型，不包含账号、游戏名称、个人路径、原始设置或认证凭据。
安装版可从设置 → 应用维护或 Windows 设置卸载；取消卸载确认会保留应用运行，确认后按认证、保存、正常退出顺序处理。卸载信息不完整时重新运行安装包修复。
卸载保留独立数据与恢复副本，清理活动程序、自启、快捷方式和当前卸载项；不会清除时长、规则和认证配置。升级保留同级 SteamWatch.previous-*，失败会保留 staging/事务日志；重复安装会增加磁盘占用。确认新版本正常、备份完整且不再需要回退后，可自行清理明确属于 SteamWatch 的旧副本，不要删除当前卸载管理目录或独立数据。

五、认证与通知
常规设置即时保存；提醒和强退、认证保护分别点击“保存设置”，只提交当前分区。离开未保存分区时可选择保存并离开、放弃修改或继续编辑；保存失败或认证取消会保留草稿。
“放弃本次修改”恢复当前分区的已保存值；认证密码输入随保存成功或放弃清空。常规设置保存不会清除其他分区草稿。
开启认证后，修改规则、保存设置、暂停/恢复限制、备份恢复、应用内卸载和退出需要认证。
密码采用带盐哈希保存；这是个人自我约束辅助，不能对抗任务管理器、本机文件编辑或系统卸载。
系统通知失败会回退程序内提醒，诊断文件只记录时间、类别和错误类型。
全屏通知被抑制时，在 Windows 设置 → 系统 → 通知检查勿扰模式，以及玩游戏/全屏应用的自动规则。
关闭窗口默认进入托盘，未保存草稿会保留。正式退出、升级退出和应用内卸载会先处理设置草稿，可选“保存并退出”“不保存并退出”或“继续编辑”；再按最新认证配置验证并保存运行数据。认证取消或保存失败时继续运行，未保存草稿保留；已有保存、导航或对话框尚未结束时，请完成后重试退出。

六、帮助与设置
帮助页顶部可直接进入提醒设置、认证保护和备份诊断；底部“关于”显示当前版本与安装/绿色版状态。常规设置按行即时保存；保存成功显示短反馈，错误与认证取消保持提示。认证关闭时新密码框禁用，开启后可编辑。绿色版维护页提供移除说明，不显示安装版卸载按钮。
