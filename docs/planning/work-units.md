# 既有 WU 实施合同

现有 17 个 ID 保留，依各自完成定义交接；实时状态只见 本地 `STATUS.md`，阶段/依赖索引见 本地 `PLAN.md`。这些是任务合同，不是本次已执行记录。

## 共同输入、非范围与交接

输入为 [PRD](../product/PRD.md)、[SPEC](../../SPEC.md)、[交互](../design/interaction-contract.md)、[架构](../architecture.md)、[数据](../architecture/data-model.md) 与 [测试策略](../test-strategy.md)，基线见 [baseline-v2](../baseline-v2.md)。依据具体任务读取相关部分，无需加载全部历史。

非范围：不默认新增产品能力、依赖/平台升级、无迁移的数据格式变更、全局安装工具或操作主安装/正在游玩的游戏；不 commit/push/远程 CI/正式发布。任何协议/数据改动先明确兼容与恢复。保留未提交工作，不强杀用户进程，不把旧证据计作当前复验。

实施顺序：核对入口/输入→聚焦增量修改→必要失败路径回归→最终产物/源码核对。失败保留现场及用户数据，能够重试的恢复门/任务不能遗留半停止状态。代码回滚与数据降级分开处理。

交接一律给出实际文件/行为差异、命令与证据、失败恢复、未覆盖范围及 STATUS 更新；不在本文件保存测试数量或完成勾选。以下每项的验收描述就是独立完成定义。
