# 已知问题与预览范围

本页说明 2.0 预览系列的适用范围与未覆盖场景，不把“未检查”写成“已兼容”。具体版本变化见 [更新记录](../CHANGELOG.md)。

## 当前范围

- 面向 Windows x64 个人自用，提供绿色 ZIP 与当前用户安装器。
- 本机验证环境包含 Windows 11 x64；其他 Windows build、干净系统、x86 / ARM64 尚未完成专项验证。项目声明的最低平台版本不等于该平台已实测。
- 预览包未签名，Windows 下载或启动时可能警告或按系统策略拦截。项目不要求用户关闭系统安全功能。
- 系统浅/深主题、高对比度以及实际 100/150/200% 缩放未完成完整矩阵；应用内主题抽样不能代替这些结果。
- 用户已反馈普通游戏计时、休眠与跨午夜正常；周一跨周、长时运行、全屏/勿扰通知、反作弊和权限差异仍未完整覆盖。

## 偶发空白窗口

开发桌面自动化中出现窗口框架存在、无障碍树有内容，但截图空白且真实双击未响应的情况。最新候选与旧包同期复测均曾出现；恢复窗口、提前激活未解决。临时重置显示空闲计时后，同一候选的启动与完整桌面回归恢复正常，本机显示器闲置关闭设置为5分钟。此证据支持显示状态相关的判断，但未证明此前所有空白均由此造成，仍保留未确认根因的限制。

测试工具可在测试期间临时保持显示唤醒并在结束后释放，不改变系统电源方案。应用自身不因此常驻亮屏；自动化结果也不代替用户日常环境的显示恢复检查。

若发生，请记录版本、Windows build、显示缩放、从根启动器还是载荷启动、是否重复启动或刚恢复窗口；在能够操作时导出诊断。截图只保留相关窗口，不公开完整 data 或备份文件。重复启动结果只能作为排查证据，不能证明所有环境都无此问题。

## 使用边界

- 本地实测存在进程采样误差；Steam 差值估算不代表真实发生日期，也不参与限额。
- 暂停限制仍继续计时。单游戏与全部游戏规则同时生效；多个游戏同时运行时全局用量相加。
- 强退策略可能结束未保存进度的游戏，应主动选择并先在可丢弃进度场景体验。特定权限、反作弊或系统通知策略可能影响执行与提醒可见性。
- 应用内认证用于自我约束，不构成操作系统级防绕过保护。
- 2.0 账本升级后不支持直接交给旧版写入。回退应恢复升级前的数据备份，不能只换回旧 EXE。

问题反馈入口：[GitHub Issues](https://github.com/lyclycNSP/SteamWatch/issues)。提交版本、环境、复现步骤、预期和实际结果即可；诊断包可先自行检查，不上传完整备份或认证信息。
