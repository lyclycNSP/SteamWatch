## 页面与操作入口

| 页面 | 结构 | 操作与焦点合同 |
| --- | --- | --- |
| 游戏（默认） | 顶部全局每日预算/每周预算/最早强退；搜索/组合筛选、游戏列表、底部操作 | 单击选择，双击限额；右键固定目标的限额/详情/强退/分类，关闭回原目标；无库/规则切换 |
| 统计 | 每日/每周标签、各自日期、实测/估算/合计，七日趋势及等价数值 | 周一开始，切页/刷新保留日期；修正回同一上下文，图表有可访问描述 |
| 设置 | 带图标分隔导航；常规说明左/控件右，提醒/认证显式保存；维护独立入口 | 不同分区草稿不互相覆盖，离开保存/放弃/继续编辑；认证取消留原分区 |
| 帮助与关于 | 常用设置捷径、五项直读指南、关于版本/模式 | 不含启动程序，不用折叠指南；捷径只导航，指南末尾一条分隔线 |

游戏列表显示图标/名称/运行状态/今日与本周实测/单游戏限额，AppID 可搜索，Steam 累计在详情；缺失累计不显示假零。运行项靠前，筛选无结果不清空其他筛选；刷新保留 AppID 选择/滚动，失效目标清空。目录外仅有规则的条目仍可管理。

顶部总预算显示实测用量/上限/剩余/策略，日与周各自编辑固定全局目标。未设置显示实际用量和未设置，超限有文字/图形，图形上限 100%；无运行目标/暂停/仅提醒不得有伪倒计时。示例值仅用于画图，不新增默认限额。

规则编辑统一目标、日/周、整数分钟、策略、影响说明、保存/取消/删除；日周切换读对应规则。强退风险与当前倒计时说明可见，默认不选强退；非有限/非整数/越界和身份冲突留表单提示，认证前捕获目标/候选。规则编辑含认证交接拒绝正式退出。

## 通用状态与反馈

| 状态 | 呈现 | 可操作边界 |
| --- | --- | --- |
| 首次加载 | 页内加载指示和具体读取阶段，不做欢迎模态框 | 未完成初始化不提交敏感修改；允许帮助，不显示假默认规则/零时长 |
| 正常待机 | 监控正常、没有运行游戏；保留游戏目录 | 可筛选、编辑、查看统计；不显示过期倒计时 |
| 运行中 | 运行状态、实测、有效规则；摘要来自真实运行快照 | 操作不阻塞后台采样；不以 UI 定时器另算执行截止时间 |
| 限制暂停 | “限制已暂停 · 仍在计时”，恢复按钮 | 无提醒/强退威胁；恢复遵循原新宽限规则 |
| 仅提醒/无规则 | 明确文字，无倒计时/虚假剩余额度 | 规则编辑可用；不默认切为强退 |
| Steam 未发现/缓存暂缺 | 区分目录、缓存和无运行目标，提供刷新与帮助 | 保留已读历史；不清空账本或补记游标 |
| 空列表 | 区分空库与筛选无结果 | 可刷新或清除筛选；未知/工具不因缺元数据自动隐藏 |
| 保存/恢复中 | 忙碌反馈与防重复提交 | 持久化提交开始后不提供会打断事务的取消；其他读取按运行状态处理 |
| 保存失败 | 持续错误 InfoBar，可重试、可导出脱敏诊断 | 不发布假成功；即时控件恢复持久化值，显式草稿保留；保存失败不强退 |
| 认证取消/密码错误 | 取消说明或可操作错误，返回原动作上下文 | 不改数据、不复用默认免认证期；后续新操作重新授权 |
| 编辑过期/目标冲突 | 表单内指出变更并提供重新加载 | 不静默覆盖，不因切换列表行更改正在提交的目标 |
| 升级退出等待 | 升级动作说明；共用认证与对话框调度 | 认证取消、超时、保存失败保留程序；安装器不读取密码 |

限额与强退提醒只保留一个未确认的最新提示：等待编辑/认证弹窗时覆盖待显示消息，提醒已显示时原位更新，确认一次关闭，不积压历史提醒；后台计时不中断。系统通知和声音沿用原规则，保存错误等操作反馈不参与此合并。键盘焦点在关闭对话框后回发起控件，周期快照不得抢焦点。退出准备挂起期间不再发起新的应用内通知弹窗。

同一次展示更新使用同代运行快照与同一本地日期，游戏、预算、统计及图表不得分别读取不同代数据。统计切换日期/周期使用最近展示快照；手动刷新成功立即应用其返回快照。刷新和暂停命令忙碌期间拒绝重复请求及退出，退出准备期间挂起新请求；取消/失败恢复后应可继续刷新、暂停和恢复，保留设置草稿。

## 设置草稿、共享命令与退出

常规即时保存，提醒/认证显式保存当前分区；无效输入先提示，不先认证。成功/放弃短反馈约 5 秒，错误/取消保持；保护关闭时禁新密码框，保存或放弃清密码。绿色维护页给移除说明，安装版才给卸载入口。

离开草稿是保存并离开/放弃修改/继续编辑；真正退出是保存并退出/不保存并退出/继续编辑，默认继续编辑。不保存不立即清 UI，后续认证取消/失败仍保留。按保存后的最新凭据认证；关闭到托盘保留草稿，准备期间锁导航和编辑，失败恢复。行为顺序以 FR-SET-001/FR-EXIT-001 为准。

规则/分类/估算/维护从弹窗、认证、系统选择器到写入完成共用忙碌门，拒绝新命令/导航/退出并禁设置；取消/失败释放，保留相应草稿。卸载直接用退出准备，不能嵌套占门阻止自身。页面卸载停展示订阅，不停运行监控；旧附着代次通知不能弹窗。

## 排版与适配

- 系统字体与中文回退；层级 28/18/14/12 DIP，间距 4/8/12/16/24/32，使用系统主题资源和共享 DesignResources。
- 标签为下划线单选态；摘要连续分隔，列表表头和行共列宽，长名称可在详情读全。设置/帮助按 SizeChanged 限视口及 760 DIP，防缩窗裁切。
- 多行弹窗正文 24 DIP 行高、自动换行；段/详情行/每日数值间距 12 DIP，估算记录间距 20 DIP；长内容滚动，保留标题、按钮与输入模板。
- 状态同时用文字/符号，不只靠颜色；浅/深/高对比度和键盘/读屏均需验证。候选 1120×760、800×600 DIP，100/150/200% 实际检查，不从概念图推出可用性。
- 对话框关闭还焦点，周期刷新不抢焦点；图表保留文字/等价数据入口；图标用实际本地游戏图标和系统符号。
